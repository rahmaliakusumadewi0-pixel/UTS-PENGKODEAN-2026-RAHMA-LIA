## Deskripsi Proyek

Repositori ini dibuat untuk mengumpulkan artefak pendukung pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pengkodean dan Pemrograman. Proyek ini berfokus pada perancangan purwarupa **Voucher Entri Transaksi Kas Keluar** berbasis web sesuai kebutuhan akuntansi dan pengendalian internal.

Repositori mencakup purwarupa antarmuka, dokumentasi penggunaan AI, rancangan database, serta spesifikasi validasi transaksi dan audit trail.

## Daftar Artefak

### 1. Purwarupa HTML

**File:** https://github.com/rahmaliakusumadewi0-pixel/UTS-PENGKODEAN-2026-RAHMA-LIA/blob/main/gemini%20canvas.html

**Hasil Gemini:** [voucher_entri_kas_keluar.html`](https://share.gemini.google/t30UU31DLKp4)

Berisi purwarupa antarmuka voucher entri kas keluar yang menggambarkan rancangan tampilan dan alur input transaksi, termasuk pencatatan akun, nominal debit dan kredit, serta indikator keseimbangan jurnal sesuai kebutuhan tugas.

### 2. Log Prompt AI

### 3. Dokumen Jawaban UTS

Dokumen jawaban UTS memuat pembahasan sesuai instruksi tugas, meliputi spesifikasi sistem, rancangan database, validasi jurnal, serta mekanisme audit trail yang relevan.

### 4. Spesifikasi Backend dan Audit Trail

Memuat rancangan fungsi dan trigger PostgreSQL untuk menjaga integritas jurnal, mengunci transaksi berstatus `POSTED`, menerapkan mekanisme *reversing entry*, serta mencatat informasi audit dan checksum SHA-256.

### 5. Verifikasi Standar Akuntansi Menggunakan NotebookLM

Memuat ringkasan hasil analisis terhadap ketentuan akuntansi terkait kas dan setara kas, termasuk pemeriksaan aturan bisnis yang relevan dengan sistem. Hasil verifikasi disesuaikan dengan sumber dan kode yang benar-benar tersedia.
